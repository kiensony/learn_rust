# task-064 — Loose tiles · one reading

After making rows of 2, return the number of tiles left over.

```rust
pub fn loose_tiles_2(value: u16) -> u32
```

Implement the public function in `src/lib.rs`.

Read the signature from left to right. Parentheses contain the inputs. The type after `->` tells you what the caller receives. Predict the first example before editing.


## Public examples

- `loose_tiles_2(4)` gives `0`.
- `loose_tiles_2(13)` gives `1`.

## Run this exercise

From the course root, run `cargo test --manifest-path tasks/task-064/Cargo.toml --test public`. After the examples pass, complete the submission step in REVIEW.md and run `cargo track test task-064`.
