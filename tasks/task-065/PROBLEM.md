# task-065 — Mirror a coordinate · one reading

Find the distance between the coordinate value and the marker 2.

```rust
pub fn mirror_a_coordinate_2(value: u16) -> u32
```

Implement the public function in `src/lib.rs`.

Read the signature from left to right. Parentheses contain the inputs. The type after `->` tells you what the caller receives. Predict the first example before editing.


## Public examples

- `mirror_a_coordinate_2(4)` gives `2`.
- `mirror_a_coordinate_2(13)` gives `11`.
